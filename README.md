# Telegram-бот с реакциями на ключевые слова

Бот для групповых чатов, который с определённой вероятностью отправляет случайную картинку, если в сообщении встречается ключевое слово.

## Возможности
- Реакция на слова-триггеры (точное совпадение)
- Несколько картинок на одно слово (случайный выбор)
- Настраиваемый шанс срабатывания (по умолчанию 50%)
- Команда `/ping` для проверки работоспособности
- Уведомление администратора об ошибках отправки

## Технологии
- Python 3.10+
- aiogram 3.x
- python-dotenv
